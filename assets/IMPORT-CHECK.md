# Godot import check

Tool: `make assets-check` runs `godot/viewer/asset_check.gd` headless. It loads every glTF/GLB listed
in `assets/manifest.json` at runtime with `GLTFDocument` (`append_from_file` then `generate_scene`),
walks the resulting scene, and exits nonzero if any file fails. Engine: Godot 4.7.2 stable (mono), run on
2026-11-10. Results below are from that run: **40 files, 40 OK, 0 failed.** No model had to be removed from the manifest.

## Kenney Car Kit GLB validation issue

A forum thread (PlayCanvas) reported Car Kit GLBs failing validation or loading in that engine. In
Godot 4.7.2 all 16 committed Car Kit GLBs (kit version 3.1, generated by UnityGLTF) load without error, with
the expected node, mesh and triangle counts and sensible bounding boxes (about 1.5 x 1.3 x 2.6 m for a sedan). The
only unusual feature is a `KHR_texture_transform` extension on the base-colour texture; Godot ignores it
harmlessly. The Godot GLTF importer does not run the Khronos validator, so this checks "loads and yields sane
geometry in Godot", not strict spec conformance.

## Flat colour check

Material kinds: `flat` = albedo colour only, `vertex` = vertex colours, `textured` = a texture is referenced.

- **All 40 pack models reference an albedo texture; none is purely flat or vertex colour.**
- Kenney Car Kit and City Kit (Suburban) (28 models): the texture is one shared 12 KB palette atlas
  (`Textures/colormap.png`) that UV-maps each face onto a solid swatch. Visually flat colour, but a texture
  dependency in the file. A loader that wants strictly material colours would have to bake or replace it.
- Quaternius MegaKit (12 models): alpha-cut diffuse textures for leaves, flowers and grass (`Leaves.png`,
  `Flowers.png`, `Grass.png`, `Leaves_*_C.png`); stylised but not flat-colour. The tree models of the pack
  also use bark diffuse and normal maps and were not included.
- Primitives (`prim:wall`, `prim:slab`, `prim:pot`) are pipeline meshes with per-face flat colours; they have no file and
  are not covered by this check (they are covered by `pipeline/tests/test_primitives.py`).

Note: sizes are Godot/glTF axes, x width, y height, z depth. Kenney City Kit (Suburban) pieces are authored small
(tree 0.77 m, fence section 0.5 m) and need scaling when placed.
