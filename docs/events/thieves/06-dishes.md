# 06 Dishes

Satellite dishes on houses, generated by the pipeline, and stealing them. Introduces the climb used by 07.

## Facts
- Not modelled today (`flats.py`, `loggia_house.py` say so). Synty's dishes are large military ground units.
- House connectors are the model to copy: 139 placed objects on walls under the eave / on roofs, picked by `house_connections.py` (`docs/utility-poles.md`), in `objects.json`, present on the server as nodes.
- Placed objects are not replicated; `MapLoader.ApplyObjectChanges` is a local edit.
- Generated models: `scripts/make_bus_model.py` and friends, into `assets/drycastle-generated-models/`.

## Do
- Model: a small household dish (~0.7 m) with a wall arm, generated by a script, public, in the manifest with licence note.
- Pipeline: a seeded chance per house (`dish_chance`, 0.4, in `rules.yaml`), on a wall under the eave facing the nearest road, clear of windows and of the connector; written to `objects.json` as a placed object (visible and movable in the editor). Stable ids across rebuilds. Tests; `docs/pipeline.md`.
- Server: dish targets = those object nodes. State "taken" per dish id, sent as a reliable event (set of taken ids to a joiner); client hides or shows the object node. Reset on round start.
- Climb: a scripted move for a gang member: stand at the wall base under the dish, `Climb` up to it at `climb_speed`, Steal there, climb down, Haul. Clip names `climb_up` / `climb_down` / `climb_work` (made in 08; until then a held reach pose). Shot dead on the wall: falls (as the pole fall in 07) and the dish, if already taken, lies at the base.
- Dish prop carried in both hands; lying dish; return puts it back on the wall.

## Accept
- Tests: placement is seeded and stable; no dish on a wall with no room; taken set survives a join; climb reaches the dish height and returns to the base.
- Village map rebuilt with dishes (MAP=out/village/map); everything else in the map unchanged.

## Pipeline half: done (`12e3b5d`)
- Model `pack:drycastle-generated-models/satellite_dish` (`scripts/make_satellite_dish_model.py`), nodes `mount`, `dish`, `lnb`; origin on the wall, +X out of the wall; about 0.67 x 0.66 x 0.70 m.
- Placement is a command like the house connectors, not a build step: `cd pipeline && uv run python -m drycastle_pipeline.dishes` appends dishes to `edits.json` (seeded per building, reruns only add). Rules: `dishes:` in `rules.yaml`. `docs/pipeline.md` "Satellite dishes".
- The game finds dishes as objects of `objects.json` with that asset; `rotation_deg` = the way the wall faces, `z` = elevation of the origin.
- Category is `other` (so the editor palette shows it): the game gives it a default box collider. Game half: no collision for the dish.
- Not run on the village yet (the main tree's `edits.json` is live): the owner runs the command, then `make map-update MAP=out/village/map`. Until then the map has no dish: the game must cope with zero dish targets.
