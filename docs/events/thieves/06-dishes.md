# 06 Dishes

Satellite dishes on houses, generated by the pipeline, and stealing them. Introduces the climb used by 07.

## Facts
- Not modelled today (`buildings/landmarks/flats.py`, `buildings/landmarks/loggia_house.py` say so). Synty's dishes are large military ground units.
- House connectors are the model to copy: 139 placed objects on walls under the eave / on roofs, picked by `edits/house_connections.py` (`docs/utility-poles.md`), in `objects.json`, present on the server as nodes.
- Placed objects are not replicated; `MapLoader.ApplyObjectChanges` is a local edit.
- Generated models: `scripts/models/make_bus_model.py` and friends, into `assets/drycastle-generated-models/`.

## Do
- Model: a small household dish (~0.7 m) with a wall arm, generated by a script, public, in the manifest with licence note.
- Pipeline: a seeded chance per house (`dish_chance`, 0.4, in `rules.yaml`), on a wall under the eave facing the nearest road, clear of windows and of the connector; written to `objects.json` as a placed object (visible and movable in the editor). Stable ids across rebuilds. Tests; `docs/pipeline.md`.
- Server: dish targets = those object nodes. State "taken" per dish id, sent as a reliable event (set of taken ids to a joiner); client hides or shows the object node. Reset on round start.
- Climb: a scripted move for a gang member: stand at the wall base under the dish, `Climb` up to it at `climb_speed`, Steal there, climb down, Haul. Clip names `climb_up` / `climb_down` / `climb_work` (made in 08; until then a held reach pose). Shot dead on the wall: falls (as the pole fall in 07) and the dish, if already taken, lies at the base.
- Dish prop carried in both hands; lying dish; return puts it back on the wall.

## Accept
- Tests: placement is seeded and stable; no dish on a wall with no room; taken set survives a join; climb reaches the dish height and returns to the base.
- Village map rebuilt with dishes (MAP=out/village/map); everything else in the map unchanged.

## Pipeline half: done (`12e3b5d`)

- Placement is a command like the house connectors, not a build step: `cd pipeline && uv run python -m drycastle_pipeline.edits.dishes` appends dishes to `edits.json` (seeded per building, reruns only add). Rules: `dishes:` in `rules.yaml`. `docs/pipeline.md` "Satellite dishes".
- The game finds dishes as objects of `objects.json` with that asset; `rotation_deg` = the way the wall faces, `z` = elevation of the origin.
- Category is `other` (so the editor palette shows it): the game gives it a default box collider. Game half: no collision for the dish.
- Not run on the village yet (the main tree's `edits.json` is live): the owner runs the command, then `make map-update MAP=out/village/map`. Until then the map has no dish: the game must cope with zero dish targets.

## Done: notes
Game half. Protocol 48 (merge renumbers); event kind 233 `DishTaken`.

### Code
- Pure, `godot/ShooterCore/Thieves/DishTarget.cs`: `DishLootConfig` (`loot.dish`: `base_out_m` 0.9, `snap_max_m` 1.2, `snap_max_dy_m` 1.0, `reach_below_m` 1.3, `min_climb_m` 0.4), `DishSite` (object id, origin, yaw), `IDishWorld` (sites, ground, mesh snap), `DishSource : IStealSource`, `DishCodec`, `DishSource.AssetId`.
- Server, `NetServer.Thieves.Loot.Dish.cs`: `ServerDishes` (sites from `Map.ObjectNodes` with that asset, sorted by object id; cached once the nodes are in the tree), `MakeDishSource()`, `SendDishesOnJoin`.
- Client: `ThievesClient.cs` (`OnDishEvent` -> hides/shows the object nodes), `LootProp.Dish.cs` (generated model, box fallback).
- Collision: `ObjectColliders.IsPassThrough(asset)` (the dish asset), checked first in `MapLoader.AddObjectColliders`: no body on server or client. Category stays `other` (editor palette).
- Tests `DishTests.cs`.

### Decisions
- Source id = index into the sorted dish list; the wire carries object ids (strings, whole set, u16 count + u8 len + utf8), so a client whose list differed hides nothing wrong.
- Target: `Position` = dish origin, base = origin + out * `base_out_m` (out = +X turned by `rotation_deg`, as `FirstObjectOfAsset`), ground from `GroundHeight`, snapped to the mesh = `WorkSpot`; off the mesh (flat or height limit) = no target, not a van place. `Top` straight above, y = max(origin y - `reach_below_m`, base y + `min_climb_m`). Computed once per dish, not cached while there is no mesh.
- Taken set: `Take`/`Return`/`Reset` fire `TakenChanged` -> broadcast whole set; round start and cancelled event reset through the registry (no extra hook). Joiner gets it when non-empty. Lying dish = generic lying Loot (default `LiesWhenDropped`).
- Client shows/hides nodes only on the event (a map edit that re-creates a node in the editor is not re-hidden).
