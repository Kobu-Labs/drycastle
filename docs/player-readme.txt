SUCHOHRAD SHOOTER

1. Unzip this whole folder (right-click > Extract All). Do not run the game from inside the zip.
2. Double-click suchohrad-shooter.exe.
3. If Windows says "Windows protected your PC": click "More info", then "Run anyway".
4. Enter the server address (and port, if you were given one) on the connect screen, then press Connect.
   The game remembers it for next time.

Keep the "assets" and "map" folders next to the exe; the game needs them.
If it will not connect: check the address, and ask the host whether the server is running.
