# UI/UX holds an AAA standard from the first version, for every screen

Menus and UI ship polished from the start, including the map editor and developer tools, with predictable flow and sensible controls (`mods/methodology.md`). We defined the standard in `docs/standards/ui-ux.md` and made its checklist part of the acceptance criteria of every UI issue, rather than leaving polish for a later pass. Cost: UI issues are slower and larger; accepted, because retrofitting flow and input handling later is more expensive and the owner treats it as non-negotiable.
