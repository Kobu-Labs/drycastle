# Suchohrad Game

A GTA-like open-world game set in the real village of Suchohrad (Slovakia), in a simplified low-poly style. The base map is generated by a re-runnable, fully scripted pipeline from open data, with no manual map building. Mods (for example the shooter PoC) are separate games built on that base map.

## Repo layout

| Path | What it is |
| --- | --- |
| `pipeline/` | Python (uv) project that generates the base map. Package `suchohrad_pipeline`, one stub per stage. |
| `pipeline/config/` | Rules, manual building overrides and hand edits (`edits.json`) for the pipeline. |
| `godot/MapLoader/` | C# class library, shared runtime loader for chunk glTF and parcel replacement. |
| `godot/netspike/` | Godot C# project, 64-client headless netcode spike (issue #18); report in `docs/spikes/netcode-spike.md`. |
| `godot/viewer/` | Godot 4.7 C# project for looking at the generated map. |
| `mods/shooter/` | Shooter PoC (stub). Design notes are in `mods/shooter.md`. |
| `docs/` | Pipeline and viewer/editor reference, UI standard, ADRs (`docs/adr/`). `GLOSSARY.md` defines the domain terms. `docs/brief.md` is the original project brief. |

## Pinned versions

- Godot 4.7.2 mono (also in `.godot-version`)
- .NET 8 (SDK 8.0)
- Python 3.13 (`pipeline/.python-version`; `uv` installs it if missing)

## Setup

Requires `uv`, `make`, the .NET 8 SDK and Godot 4.7.2 mono on your `PATH` as `godot`.

```sh
make setup    # uv sync in pipeline/
make test     # pytest
make lint     # ruff check
```

## Running

```sh
make map        # run every pipeline stage in order (fetch ... export)
make fetch      # run only the fetch stage (downloads raw data into data/raw/)
make normalise  # raw data -> local metres in data/work/normalised/
make parcels    # parcel registry, kinds, building assignment; prints a report
make rules      # building heights, roofs, colours -> data/work/buildings.json
make terrain    # DMR 5.0 -> height grid, ground flattened under buildings (data/work/terrain*)
make roads      # OSM highways -> road graph (data/work/roads.json)
make props      # fences, trees, spawn candidates (data/work/props.json, spawns.json)
make export     # chunk glTFs, parcels.json, roads.json, spawns.json, manifest.json -> out/map/
make preview    # out/preview/topdown.png, iso.png, iso_close.png (matplotlib; EXAG=3 relief factor)
make map AREA=village   # the same for the whole village (any target takes AREA=slice|village)
make viewer         # build and run the Godot viewer (see docs/viewer-and-editor.md)
make viewer-smoke   # headless smoke test of the viewer and the loader
make viewer-edit-smoke  # hot reload end to end (scratch export, headless viewer, edits written during the run)
make viewer-shot    # windowed run, writes PNGs to out/screens/
make netspike-quick # netcode spike, N=8, 15 s (needs a map: MAP=/path/to/out/map)
make netspike       # netcode spike, N=16/32/64, 60 s per variant (about 30 minutes)
```

To build the C# projects without the editor:

```sh
dotnet build godot/MapLoader/MapLoader.csproj
dotnet build godot/viewer/viewer.csproj
```
